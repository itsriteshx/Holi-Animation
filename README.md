# 🎨 Holi Animation

A fun and interactive web project that creates a **color splash (Holi effect)** on mouse click. Every click generates beautiful animated color particles on the screen.

---
## ✨ Features

- 🎯 Click anywhere to generate color splash
- 🌈 Random colorful particles
- 💥 Smooth fade-out animation
- 🖥️ Works in browser (no setup required)
- 📱 Simple and lightweight project

---

## 🚀 Demo

👉 Open `index.html` in your browser  
👉 Click on the screen to see color explosion
